# Security policy

Do not report vulnerabilities in a public issue or include secrets, account details, or student data in a report.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Security** tab to submit a private report. Otherwise, contact the repository owner through GitHub and ask for a private reporting channel. Include steps to reproduce and the affected area; avoid accessing or changing other users' data.

This project is actively maintained, but response and remediation timelines are not guaranteed.
